1认识马尔科夫性：只看"现在"

系统的下一个状态，只取决于现在这个状态，与更早的历史无关。这叫马尔科夫性（无后效性）。
P(下一个 = j | 现在 = i, 更早的历史) = P(下一个 = j | 现在 = i) = p(ij)

例：一个三状态的天气链

今天 → 明天晴多云雨
晴0.600.300.10
多云0.300.400.30
雨0.200.400.40
每一行的三个数相加都是 1：从某个状态出发，一定会跳到三种状态之一。这个表就叫转移概率矩阵。

2为什么要加权：让历史按"可信度"发言

某地"连续三年偏丰"和"只有去年偏丰"，明年的降水量会一样吗？显然不一样。
相隔 1 年、2 年、3 年的历史，对当前的影响力度不同。所以：让每一阶各预测一次，再按各自的"可信度"加权平均。
可信度 → 自相关系数 r(k)　　权重 w(k) = |r(k)| ÷ Σ|r(k)|　，　Σw(k) = 1

动手：拖动权重，看结论会不会变

综合后的预测

两个容易搞错的点：
1）权重是算出来的（来自数据），不是老师按经验打的分；
2）r(k) 为负时取绝对值继续参与加权，是教材里常见的简化处理。

3四步流程 + 一个完整算例

  1. 划分状态：把原始数据变成 1、2、3…（阈值怎么定会影响结论）
  2. 统计各阶转移矩阵：k = 1, 2, …, m 阶，行内频数 ÷ 行和 = 概率
  3. 算自相关系数并定权：w(k) = |r(k)| ÷ Σ|r(k)|
  4. 加权预测：p(j) = Σ w(k) × p(ij)(k)，取概率最大的状态
算例：某地 25 年的年降水状态（1 偏枯 / 2 正常 / 3 偏丰），最近三年连续都是"正常"。

② 从"正常年"出发的三阶预测分布

阶 k偏枯正常偏丰
1 阶12.5%50.0%37.5%
2 阶14.3%14.3%71.4%
3 阶16.7%16.7%66.7%

③ 自相关系数 → 权重

阶 k自相关 r(k)权重 w(k)
1 阶+0.6080.480
2 阶+0.4000.316
3 阶+0.2580.204
越近的历史相关越强，权重也越大；三者相加 = 1.000。

④ 加权（把上面的数字真实算一遍）

偏枯：0.480×12.5% + 0.316×14.3% + 0.204×16.7% = 13.9%
正常：0.480×50.0% + 0.316×14.3% + 0.204×16.7% = 31.9%
偏丰：0.480×37.5% + 0.316×71.4% + 0.204×66.7% = 54.2%
结论：加权预测是"偏丰"，概率 54.2%。
而只看最近一年（一阶）只能得到"正常 50.0%"——同样的数据，把历史信息按可信度加权后，结论被改写了。
这就是加权马尔科夫链在教学里最值得记住的一幕。
补充：真实研究中，"加权之后是不是更准"要用留出数据检验，不能想当然；阶数 m 一般取 3~5，且要求序列长度 n ≥ 20~25。
